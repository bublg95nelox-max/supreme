# Frontier — Серверный мод для Minecraft 1.21.1 (NeoForge)

Мод для полуанархического SMP-сервера с механикой живого фронтира, естественного формирования государств, прецедентного права, физических расследований (криминалистики) и дипломатии.

---

## 🌟 Ключевые концепции

1. **Мягкое право вместо «неуязвимых коробок»**:
   * На сервере нет искусственных неуязвимых приватов. Любой игрок технически волен действовать, но любое преступление на признанной территории оставляет физические улики.
   * Нарушение законов расследуется самими гражданами и судьями государств, а не автоматическими банами.
2. **Физическая детективная криминалистика (Forensic Engine)**:
   * Нарушители оставляют улики в зависимости от экипировки и стиля движения:
     * **CLEAR (Явный)**: бег в тяжёлой броне (железо/незерит), применение динамита, артиллерии Create. Оставляет чёткие отпечатки, тип инструмента и нагар.
     * **PARTIAL (Частичный)**: стандартный шаг, лёгкая броня.
     * **FAINT (Слабый / Микрослед)**: передвижение на Shift (крадучись), кожаная обувь или её отсутствие.
   * Улики размываются со временем (свежие <15 мин, остывающие <1 ч, старые <24 ч).
   * Дознаватель может извлечь вещественное доказательство с места преступления — физический предмет **«Заметка криминалиста»**, который можно прикрепить к судебному делу.
3. **Хартии государств и защита от абьюзов**:
   * Создание государства происходит через систему петиций и утверждение куратором сервера (администратором), что исключает фантомные захваты чужих баз.
4. **Судебный трибунал и статус «В розыске» (Wanted)**:
   * Судьи рассматривают открытые дела. При вынесении вердикта «Виновен» нарушитель объявляется вне закона на территории этого государства. Граждане и стража получают право ликвидировать преступника без нарушения закона.
5. **Дипломатия и Война**:
   * Статусы: `Нейтралитет`, `Военный союз`, `Пакт о ненападении`, `Холодная война`, `Война`.
   * Во время официальной войны убийства и разрушения между враждующими гражданами признаются **«Боевыми действиями»** и не регистрируются как бытовые уголовные преступления.

## 🎮 Управление и Интерфейс

* Клавиша **`J`** (или команда `/frontier`) открывает главный **Кодекс Фронтира**:
  1. **Карта**: интерактивная сетка чанков с цветовой индикацией государств, нейтральных зон и диких земель, скроллом и центрированием на игроке.
  2. **Государство**: профиль страны, девиз, лидер, количество чанков, подача заявки для независимых игроков.
  3. **Законы**: реестр действующих и находящихся на голосовании правовых актов.
  4. **Дипломатия**: мировая арена отношений и заключённых пактов.
  5. **Суд**: реестр открытых расследований, привязка подозреваемых и вынесение приговоров.
* **HUD Уведомления**: при пересечении границы чанков на экран выводится название юрисдикции и действующий режим.

## 🛠 Предметы мода

* **Набор дознавателя (`frontier:detective_kit`)**:
  * ПКМ по блоку на территории государства анализирует чанк на наличие следов за последние 24 часа.
  * Shift + ПКМ: извлекает самую свежую улику в виде официального судебного протокола.
* **Заметка криминалиста / Улика (`frontier:evidence_note`)**:
  * Хранит метаданные преступления (тип, степень достоверности, подозреваемый, инструмент, время) через Data Components.
* **Инструмент землемера (`frontier:surveyor_tool`)**:
  * ПКМ: вывод юридической информации о чанке.
  * Shift + ПКМ: для лидеров/офицеров — присоединение/отключение чанка к территории; для администратора — быстрая разметка буферных и нейтральных зон.

## 💻 Консольные команды (`/frontier`)

| Команда | Описание |
|---|---|
| `/frontier` или `/frontier gui` | Открыть главное меню (Кодекс Фронтира) |
| `/frontier info` | Узнать статус и юрисдикцию текущего чанка |
| `/frontier claim` | Присоединить текущий чанк к своему государству |
| `/frontier unclaim` | Исключить текущий чанк из состава государства |
| `/frontier admin petitions` | Посмотреть список заявок на регистрацию государств |
| `/frontier admin approve <id>` | Утвердить создание государства по заявке |
| `/frontier admin neutral` | Объявить текущий чанк Нейтральной/Буферной зоной |
| `/frontier admin unclaim` | Принудительно освободить чанк (вернуть в Дикие земли) |
| `/frontier admin claim <tag>` | Назначить чанк государству по его тегу |

## ⚙️ Технические детали

* **Платформа**: NeoForge 1.21.1, Java 21.
* **База данных**: встроенный SQLite в режиме **WAL (Write-Ahead Logging)**, нулевая нагрузка на тики сервера благодаря неблокирующему асинхронному пулу потоков.
* **Кэширование в RAM**: FastUtil `Long2ObjectOpenHashMap` обеспечивает проверку границ чанка за $<5$ наносекунд.
* **Сетевой уровень**: NeoForge `CustomPacketPayload` с валидацией ролей на сервере для защиты от подделки клиентских пакетов.
* **Совместимость с Xaero's World Map**: мягкая интеграция без жестких зависимостей (мод штатно работает как с Xaero, так и без него).
