# Supreme (Optimized FPS 1.21.1)

Официальная сборка сервера **Lowuncher**.

## Характеристики
- **Версия Minecraft:** 1.21.1
- **Загрузчик модов:** NeoForge 21.1.265
- **Количество модов:** 107
- **Ключевые моды:** Create (с дополнениями Big Cannons, Connected, Diesel Generators, Additions), оптимизация FPS (Embeddium / Iris / FerriteCore / ImmediatelyFast / ModernFix), Simple Voice Chat, Sophisticated Backpacks, Tom's Simple Storage, Waystones, TreeChop, YUNG's Better Dungeons/Strongholds.

## Синхронизация
Манифест синхронизации доступен по постоянному адресу (работает без VPN):
`https://raw.githubusercontent.com/bublg95nelox-max/supreme/main/manifest.json`

Установщик NeoForge 21.1.265 включён в репозиторий (`neoforge/neoforge-21.1.265-installer.jar`) для гарантированной загрузки без блокировок.
